# aiportfoliogen
A simple web app that takes your resume (PDF or Image or txt) and uses **Google Gemini AI** to automatically build a professional portfolio website for you.

## ✨ Features
- **AI Extraction:** Upload a resume and the AI fills in your name, skills, and experience.
- **20 Designs:** Choose from 20 different professional templates.
- **Customizable:** Edit any info before generating the final site.
- **PDF Download:** Print or save your portfolio as a PDF.

## 🛠️ How to run it on your computer

### 1. Prerequisites
- Install [Python](https://www.python.org/).
- Install [Tesseract OCR](https://github.com/UB-Mannheim/tesseract/wiki) (Required for reading images/scanned PDFs).

### 2. Setup
1. Clone this folder to your computer.
2. Open your terminal in this folder and install the libraries:
   ```bash
   pip install -r requirements.txt
###3. Run the App
Start the server:
